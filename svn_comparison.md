# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git создание ветки происходит быстро, поскольку новая ветка представляет собой указатель на определённый коммит. Для её создания не требуется копировать весь проект.

В SVN ветвление реализовано через копирование каталогов внутри репозитория. Хотя SVN использует оптимизированное копирование, работа с ветками и их объединение обычно менее удобна, чем в Git.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

В SVN нельзя сделать полноценный коммит без подключения к центральному серверу, поскольку SVN является централизованной системой контроля версий.

В Git коммиты сохраняются в локальном репозитории, поэтому их можно создавать даже без интернета, а затем отправлять на сервер.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может быть удобнее в организациях, которые давно используют централизованную систему контроля версий, например в государственных учреждениях и крупных компаниях.

Также SVN может быть полезен, когда требуется централизованное управление доступом к отдельным каталогам проекта или работа с очень большими наборами файлов.
