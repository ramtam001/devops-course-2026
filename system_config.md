# Конфигурация рабочего окружения

## 1. Аппаратное обеспечение

- Устройство: Apple MacBook Air
- Процессор: Apple M2
- Архитектура: ARM64

## 2. Операционная система

- ОС: macOS
- Терминал: zsh
- Среда разработки: Visual Studio Code

## 3. Используемые инструменты

- Git — система контроля версий.
- GitHub — удалённое хранение репозитория и совместная работа.
- SSH — безопасное подключение к GitHub.

## 4. Назначение конфигурации

Данный файл содержит информацию о рабочем окружении, используемом при выполнении практических заданий по дисциплине «Инструменты DevOps».

Информация о конфигурации позволяет другим разработчикам понять, на каком оборудовании и с помощью каких инструментов выполнялась работа.
